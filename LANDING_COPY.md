## FAQ

**Is this really free?**
Yeah. The audit is free, no signup, no credit card. We make money when teams hire us to actually implement the changes — renegotiate contracts, migrate API providers, consolidate seats. If you never reach out, you never pay anything.

**What tools do you cover?**
35+ right now. Cursor, GitHub Copilot, Windsurf, Tabnine on the coding side. OpenAI, Anthropic, Groq, Google Gemini for APIs. Jasper, Notion AI, and a few others for writing/productivity. We add new ones most weeks.

**How does it actually find savings?**
Two things happen per tool. First, it checks if there's a cheaper plan on the tool you're *already* using that covers your usage — like Cursor Hobby vs. Pro based on your seat count. Second, it looks for alternative tools that do the same job for less. Everything uses published pricing, not estimates.

**Do you store my data?**
No. Your inputs aren't saved anywhere. If you choose to generate a shareable link, we store a stripped-down version of the report (no email, no company name) so the link works. Think of it like a pastebin. If you skip sharing, nothing is saved at all.

**Why not just use a spreadsheet?**
You could! But the spreadsheet can't tell you that Cursor Hobby covers your use case just as well as Business, or that Groq's API matches your OpenAI usage pattern at a third of the cost. It also can't write you a summary explaining why each change makes sense. And it'll take you a weekend instead of a minute.
